# Хэл солих (English / Монгол)

Дээд мөрөнд `МН` / `EN` товч байна. Сонголт `localStorage` (`moodtrip:lang`)-д хадгалагдана. Анх орж ирэхэд хөтчийн хэл
`mn` бол монголоор нээгдэнэ.

## Хэрхэн ажилладаг вэ

Template бүрийг `t()`-ээр солиогүй. Хуудас англиар үүсээд, орчуулга дээрээс нь хийгдэнэ (`frontend/src/core/i18n.js`):

- Дэлгэц (`VIEWS`) DOM-д орохоосоо өмнө HTML хэлбэрээрээ орчуулагдана (`I18N.html`, `render` дотор). FX гарчгийг үг үгээр
  нь хуваадаг тул энэ дарааллаар хийх ёстой.
- Дараа нь өөрчлөгдөх бүх зүйлийг (toast, sheet, review жагсаалт, `textContent`) `MutationObserver` зураг гарахаас өмнө орчуулна.
- Зөвхөн текст ба хүний уншдаг attribute (`aria-label`, `placeholder`, `title`, `alt`, `aria-valuetext`, `data-cursor`) өөрчлөгдөнө.
  `translate="no"` болон оролтын талбарт хүрэхгүй. Хэрэглэгчийн бичсэн текст, Google-ийн review орчуулагдахгүй.

Ингэснээр 4 хүн feature-ээ англиар бичсээр байна, merge conflict гарахгүй.

## Шинэ текст нэмэх

1. Хуудсаа монголоор нээгээд DevTools > Console: `MT_I18N.missing()` — орчуулгагүй харагдсан англи текстүүд.
2. `frontend/src/i18n/mn.js` → `MN_STRINGS`-д нэм. Англи текстийг **хуудсан дээр харагдаж байгаагаар нь яг** хуул.
3. Хувьсагчтай бол `{0}`, `{1}`: `"How was {0}?": "{0} ямар байсан бэ?"`. Хаалтан доторх хэсэг өөрөө орчуулагдана (Kyoto → Киото).
4. Нэрэнд тийн ялгал: `{0:gen}` Киотогийн / Хойаны, `{0:dat}` Киотод / Хойанд, `{0:acc}` Киотог / Хойаныг.
5. `" · "` болон `", "`-ээр нийлсэн жагсаалтыг хэсэг хэсгээр нь орчуулдаг тул тусад нь бичих шаардлагагүй.
6. Template-ээр илэрхийлэхэд хэцүү бол `MN_RULES`-д regex нэм (цаг 4:00 pm → 16:00, үргэлжлэх хугацаа, аялагчийн нэр).
7. `npm run build`.
